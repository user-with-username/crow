# Installation

## Grab a binary

Download from [Releases](https://github.com/user-with-username/crow/releases). Put it somewhere on your PATH. Done.

## Build from source

Need Rust installed ([rustup.rs](https://rustup.rs)):

```bash
git clone https://github.com/user-with-username/crow
cd crow
cargo install --path .
```

## Check it works

```bash
crow --version
```

## Uninstall

```bash
cargo uninstall crow
```

Or just delete the binary if you used a pre-built one.
