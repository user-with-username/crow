# CRow

**Cargo, but for C/C++**

![CRow Logo](assets/crow_logo.svg)

---

## Overview

CRow is a build system for C++ designed for developers who want:
- **Simple configuration** (just `crow.toml`)
- **Fast builds**
- **Built-in dependency manager**

---

## Quick Start

### Install
- **Pre-built binaries**: Download from [Releases](https://github.com/user-with-username/crow/releases)
- **Build from source**:
```bash
git clone https://github.com/user-with-username/crow
cd crow
cargo install --path .
```

### Create a project
```bash
crow new my_project && cd my_project
```

### Run
```bash
crow run
```
